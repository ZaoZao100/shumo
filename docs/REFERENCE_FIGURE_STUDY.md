## 后续采用的判断次序

1. 为每张图写一句它必须支持的论文结论；再判断该图是否有必要。
2. 明确比较对象、共同标尺、决策时刻和数据范围，随后选择图型。
3. 机制图突出对象、约束或操作对应关系；算法图展示可证实的状态变化。
4. 同单位同任务的小面板尽量共用坐标；不同单位不要靠堆在一起制造可比性。
5. 图负责模式与差异，表负责精确数值。避免同一批信息换两种外形重复出现。
6. 把完整论文页作为主要检查对象：图与正文的字级、相邻解释、空白和分页一起看。
7. 最后统一 restrained 配色、线宽、字体和输出质量。蓝表示主模型，橙仅用于有明确语义的风险/高值/基准，青用于已约定的正向量，其余用灰。
8. 优于有限候选、单日示例、相关性图都不能被写成超出其证据范围的证明。
